# Assignment Requirements

Extract the information from the provided invoices into CSV files using:

1. A programmatic non-LLM method (you can use an LLM to generate the code for this).
2. A low-cost LLM.
3. A more expensive LLM.
4. A refined method of your choosing that addresses the mistakes identified in the first three methods.

Compare the results from all four methods with the provided ground truth.

Submit:

- The CSV file produced by each method.
- The code for all four methods.
- A report of no more than one paragraph and one table describing the mistakes made by each method.
- One paragraph explaining the cost of each LLM method, including any use of free-tier credits or limits.
